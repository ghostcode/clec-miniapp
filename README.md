# CLEC 语录小程序

基于《理财圣经 CLEC 版》（v3.4.1）与《CLEC 宝典》（V1.14.2）两本电子书提炼的**生活 · 理财观点语录**原生微信小程序。

> 富有是天赋，快乐是人权。

## 语录来源

| 书籍 | 作者 | 说明 |
|---|---|---|
| 《理财圣经 CLEC 版》 | CLEC James（AI 编辑：Peter） | 价值十亿元的投资讲座 |
| 《CLEC 宝典》 | 布莱兹 Blaise（原着理念：CLEC 投资理财频道 James 老师） | 智慧投资者的觉醒与传承 |

语录从两书的人生哲学、投资心法章节中摘编，包括：金科玉律篇、跳出老鼠笼、物质与精神的平衡、复利与时间的魔法、觉醒的开端、富有是天赋、波动是财富的祝福、心理防线与存活哲学、买回人生选择权、扩大花钱的心量、债留银行的传承、课题分离与独立思考、投资哲学速查卡等章节。

## 功能特性

- **每日一句** —— 按日期每天固定展示一条语录，可随机「换一句」
- **今日精选** —— 首页下方每天精选 5 条（日期种子伪随机，同一天固定，不与主语录重复），支持收藏 / 复制 / 分享
- **九大分类** —— 财富觉醒 / 生活哲学 / 快乐心法 / 理财铁律 / 复利魔法 / 投资禅定 / 时间自由 / 传承使命 / 独立思考
- **关键词搜索** —— 按语录内容或来源模糊检索
- **收藏** —— 本地存储（Storage），随时查看与移除
- **复制语录** —— 一键复制「语录用 + 来源」到剪贴板
- **图片分享** —— Canvas 2D 生成精美语录卡片：
  - 4 套配色主题（宣纸 / 青瓷 / 暖阳 / 墨韵）可切换
  - 保存到相册（含权限引导）
  - `wx.showShareImageMenu` 直接分享图片给微信好友
  - 自动换行与字号自适应，超长语录不溢出
- **小程序卡片分享** —— `onShareAppMessage` 转发语录到会话

## 快速开始

1. 下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 导入本项目目录 `clec-miniapp/`
3. `project.config.json` 中当前 `appid` 为测试号（`touristappid`），正式开发请替换为你自己的 AppID
4. 编译预览即可

> 真机预览图片分享功能时，保存相册需在手机上授权；`wx.showShareImageMenu` 需基础库 ≥ 2.14.3，低版本会自动降级提示「保存后手动分享」。

## 添加 / 修改语录

编辑 `utils/quotes.js`：

```js
// 新增一条语录（id 需唯一）
{ id: 185, cat: '生活哲学', text: '语录内容……', src: '理财圣经 · 章节名' },

// 新增分类（需同时在 categories 数组中登记）
{ name: '新分类', icon: '🌟', color: '#xx', desc: '一句话简介' }
```

修改后无需改动页面代码，分类宫格、计数、徽章颜色会自动更新。

## 二次开发备注

- 语录卡片绘制采用 **750×1200 设计稿坐标系**，通过 `ctx.scale` 适配任意屏幕与 DPR
- 换行算法为逐字 `measureText` 累加；行数 > 7 时字号从 44px 逐级降至 34px 自适应
- 收藏数据结构：`favorites: number[]`（语录 id 数组，存于本地 Storage）
- 每日语录索引：`年内第几天 % 语录总数`，同一天内固定不变
